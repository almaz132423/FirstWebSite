# Business Site Template — оболочка сайта и админ-панели

Универсальный шаблон коммерческого сайта для малого бизнеса + локальная
админ-панель (редактор конфигурации). Данные, которые редактирует админка,
зеркалируют структуру Google Таблицы и Google Apps Script:

| Тип записи | Поля |
|---|---|
| `settings` | `key`, `value` — business.name, contacts.phone, contacts.address, contacts.hours, messengers.telegram.url, … |
| `service`  | `id`, `name`, `description`, `price`, `duration`, `image`, `imageAlt` |

## Структура

```
business-site-template/
├── index.html          # витрина: hero, услуги, форма записи через мессенджеры
├── admin.html          # локальная админ-панель: CRUD услуг, настройки, экспорт/импорт JSON
├── css/
│   ├── main.css        # дизайн-токены и стили витрины
│   └── admin.css       # стили админ-панели
├── js/
│   ├── config.js       # конфигурация бизнеса по умолчанию (зеркало Google Таблицы)
│   ├── common.js       # общие утилиты (экранирование, тосты, копирование, id)
│   ├── storage.js      # слой хранения: localStorage, экспорт/импорт JSON
│   ├── main.js         # рендер витрины, форма записи, генерация сообщения
│   └── admin.js        # логика админ-панели
├── config/
│   └── business.json   # пример конфигурации (можно импортировать в админке)
├── data/
│   └── sheet-mapping.md# соответствие: Google Таблица ↔ конфиг ↔ Apps Script
└── README.md
```

## Запуск

Откройте `index.html` или `admin.html` в браузере — сервер не нужен.
Для удобной разработки можно запустить локальный сервер (`npx serve .` или Vite).

## Как это работает

1. Вся информация о бизнесе живёт в конфигурации (`js/config.js` или
   импортированном JSON), а не в коде страниц.
2. Админка (`admin.html`) сохраняет изменения в `localStorage` браузера.
3. Экспорт выгружает конфигурацию в JSON-файл, импорт — загружает обратно.
4. Витрина (`index.html`) читает ту же конфигурацию: услуги, контакты,
   мессенджеры, цвета, SEO-заголовки.
5. Форма записи собирает сообщение из заполненных полей и открывает
   WhatsApp / Telegram / MAX (или копирует текст). Запись не считается
   подтверждённой, пока компания не ответит.

## Форма записи и мессенджеры

- Поля формы настраиваются в `booking.fields` (тип, обязательность, подпись) —
  логика формы при этом не меняется.
- WhatsApp: официальная ссылка `wa.me` с предзаполненным текстом.
- Telegram: официальный механизм передачи текста `t.me/share/url` —
  пользователь сам выбирает чат и подтверждает отправку.
- MAX: кнопка скрыта, пока в админке не задан официальный шаблон ссылки
  (плейсхолдер `{text}`). Недокументированные ссылки не используются.
- Всегда доступна кнопка «Скопировать текст» и подсказка после отправки.

## Анимации

Используется Anime.js с CDN. Если библиотека не загрузилась (нет сети) —
сайт полностью работает без анимаций. Для пользователей с
`prefers-reduced-motion` анимации отключаются.

## Адаптация под клиента

1. Откройте `admin.html` и отредактируйте настройки и услуги (или поправьте
   `js/config.js` / `config/business.json` вручную).
2. При необходимости замените цвета в `design.colors` — токены применятся
   на всей витрине через CSS-переменные.
3. Заполните SEO: `seo.title`, `seo.description`, Open Graph в `index.html`.
4. Добавьте реальные фотографии (только с правом использования) в
   `images/` и укажите относительные пути в услугах.

## Важно

- Это локальный редактор конфигурации, а не защищённая публичная админка.
- Для публичного редактирования с сохранением для всех посетителей нужен
  backend с авторизацией — план интеграции с Google Apps Script описан в
  `data/sheet-mapping.md` (поле `api.url` уже зарезервировано).
- Все данные в примерах — заглушки из Google Таблицы, их нужно заменить
  на реальные. Не выдумывайте адреса, отзывы и достижения.
