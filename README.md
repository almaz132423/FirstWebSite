# Business Site Template — оболочка сайта и админ-панели

Универсальный шаблон коммерческого сайта для малого бизнеса + админ-панель.
Данные, которые редактирует админка, зеркалируют структуру Google Таблицы:

| Тип записи | Поля |
|---|---|
| `settings` | `key`, `value` — business.name, contacts.phone, contacts.address, contacts.hours, messengers.telegram.url, … |
| `service`  | `id`, `name`, `description`, `price`, `duration`, `image`, `imageAlt` |

## Структура

```
business-site-template/
├── index.html          # витрина: hero, услуги, форма записи через мессенджеры
├── admin.html          # админ-панель (вход по паролю, CRUD услуг, настройки)
├── css/
│   ├── main.css        # дизайн-токены и стили витрины
│   └── admin.css       # стили админ-панели и экрана входа
├── js/
│   ├── config.js       # конфигурация бизнеса по умолчанию (зеркало Google Таблицы)
│   ├── common.js       # общие утилиты (экранирование, тосты, копирование, id)
│   ├── storage.js      # localStorage + мост к Apps Script (Google Таблица)
│   ├── main.js         # рендер витрины, форма записи, генерация сообщения
│   └── admin.js        # пароль, CRUD услуг, настройки, синхронизация с таблицей
├── apps-script/
│   └── Code.gs         # backend: чтение/запись Google Таблицы (публикуется как Web App)
├── data/
│   └── sheet-mapping.md# соответствие: Google Таблица ↔ конфиг ↔ Apps Script
└── README.md
```

## Запуск

Откройте `index.html` или `admin.html` в браузере — сервер не нужен.
Для удобной разработки можно запустить локальный сервер (`npx serve .` или Vite).

## Вход в админку

`admin.html` защищена паролем — это минимальный порог, а не настоящая защита
(всё работает на клиенте). Пароль по умолчанию: **admin123** — задан в
`js/config.js` (`auth.defaultPassword`). После первого входа смените его в
админке: «Настройки → Доступ → Новый пароль → Сменить пароль». Хэш пароля
(SHA-256) хранится в localStorage браузера; сессия входа живёт, пока открыта
вкладка.

## Работа с Google Таблицей

Сайт статический, поэтому напрямую таблицу он открыть не может — между ними
стоит Google Apps Script:

1. Откройте [script.google.com](https://script.google.com), создайте проект,
   вставьте содержимое `apps-script/Code.gs`, проверьте в нём `SHEET_ID`.
2. Разверните как веб-приложение: **Deploy → New deployment → Web app**,
   Execute as: Me, **Who has access: Anyone**.
3. Скопируйте URL `/exec` и вставьте в админке в поле «API» (Настройки →
   Форма записи и сообщение → API), нажмите «Сохранить».
4. Теперь кнопки «Загрузить из таблицы» / «Сохранить в таблицу» работают
   с листом, а витрина подтягивает свежие данные при открытии (и кэширует
   их в localStorage на случай, если таблица недоступна).

> ⚠️ «Сохранить в таблицу» перезаписывает строки данных листа (со 2-й строки).
> Перед первым сохранением сделайте копию таблицы.

## Как это работает

1. Вся информация о бизнесе живёт в конфигурации (`js/config.js`), а не в коде.
2. Админка сохраняет изменения в `localStorage` — витрина читает тот же ключ.
3. Если задан `api.url`, те же данные читаются/пишутся в Google Таблицу
   через Apps Script (настройки → строки `settings`, услуги → строки `service`).
4. Форма записи собирает сообщение из заполненных полей и открывает
   WhatsApp / Telegram / MAX (или копирует текст). Запись не считается
   подтверждённой, пока компания не ответит.

## Форма записи и мессенджеры

- Поля формы настраиваются в `booking.fields` — логика формы не меняется.
- WhatsApp: официальная ссылка `wa.me` с предзаполненным текстом.
- Telegram: кнопка открывает чат компании (`messengers.telegram.chatUrl`,
  официальный deep link `t.me/<username>`), а текст заявки автоматически
  копируется в буфер — пользователь вставляет его в чат и отправляет сам.
  Если `chatUrl` не задан, используется официальный `t.me/share/url`
  (параметр `url` обязателен: с пустым Telegram редиректит на telegram.org).
- MAX: кнопка выключена по умолчанию. Включите её в админке — шаблон уже
  содержит официальный диплинк `https://max.ru/:share?text={text}`
  ([dev.max.ru/help/deeplinks](https://dev.max.ru/help/deeplinks)): открывается
  экран «Отправить в MAX» с готовым текстом заявки, получателя выбирает
  пользователь. Текст дополнительно копируется в буфер как страховка.
  Недокументированные ссылки не используются.
- Всегда доступна кнопка «Скопировать текст» и подсказка после отправки.

## Логотип и фото витрины

В админке («Настройки → Логотип и фото витрины») можно изменить:

- **логотип** — шапка, футер и значок вкладки (favicon); без логотипа показывается значок ★;
- **фото в главном блоке (hero)** и **фото в блоке «О компании»**;
- **фото каждой услуги** (окно «Изменить услугу»).

Для каждого изображения доступны два способа: **загрузить файл с устройства** или
**вставить ссылку** (`https://…` / `images/файл.jpg`).

- Загруженные файлы автоматически сжимаются (до 1400 px, логотип — до 600 px) и хранятся
  в `localStorage` этого браузера как data:-URL. Это значит, что они видны только там, где
  их загрузили. Чтобы фото видели все посетители сайта, положите файл в `images/`,
  задеплойте и укажите путь ссылкой (или загрузите файл на хостинг и вставьте URL).
- В Google Таблицу синхронизируются только изображения, добавленные **ссылкой**
  (в ячейку помещается до 50 000 символов, data:-URL туда не влезает). Загруженные с
  устройства файлы при «Загрузить из таблицы» не затираются.
- Если браузеру не хватает места, при сохранении появится предупреждение.

## ВКонтакте и Авито

Включаются в админке («Настройки → Мессенджеры»); у каждого — своя ссылка. Кнопки
появляются в форме записи и в блоке «Контакты».

Ни VK, ни Авито не позволяют передать готовый текст сообщения по ссылке (официальных
параметров для этого нет), поэтому работает тот же механизм, что и у Telegram: кнопка
**открывает чат/профиль, а текст заявки автоматически копируется в буфер** — посетитель
вставляет его и отправляет сам.

- **ВКонтакте:** укажите сообщество — `https://vk.me/имя` или `https://vk.com/имя`
  (адрес `vk.com/имя` сайт сам превращает в диалог `vk.me/имя`). В сообществе должны быть
  включены сообщения.
- **Авито:** укажите ссылку на профиль продавца или на объявление.

## Анимации

Anime.js подключён с CDN. Без сети сайт полностью работает без анимаций.
Для пользователей с `prefers-reduced-motion` анимации отключаются.

## Адаптация под клиента

1. Войдите в `admin.html` и отредактируйте настройки и услуги.
2. При необходимости замените цвета в `design.colors` — токены применятся
   на всей витрине через CSS-переменные.
3. Заполните SEO: `seo.title`, `seo.description`, Open Graph в `index.html`.
4. Добавьте реальные фотографии (только с правом использования) в `images/`
   и укажите относительные пути в услугах.
5. После изменений задеплойте сайт заново (например, на Vercel).

## Важно

- Пароль и localStorage — минимальный порог, а не полноценная защита.
  Для настоящей авторизации нужен backend.
- Все данные в примерах — заглушки из Google Таблицы, их нужно заменить
  на реальные. Не выдумывайте адреса, отзывы и достижения.
